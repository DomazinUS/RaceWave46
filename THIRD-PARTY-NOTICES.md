## RecompFrontend provenance

The upstream RecompFrontend repository does not provide a blanket core license file at the reviewed revision. Its [initial import](https://github.com/N64Recomp/RecompFrontend/commit/bc2b1d863a68b37710127b8f537451d286ff1e9b) contains 21 files identical to the preceding [Zelda64Recomp snapshot](https://github.com/Zelda64Recomp/Zelda64Recomp/tree/54950a10408599d1d63802ee21cc2c4b05bfd378), plus closely matching UI implementations. That original project supplies [GPLv3](https://github.com/Zelda64Recomp/Zelda64Recomp/blob/54950a10408599d1d63802ee21cc2c4b05bfd378/COPYING). A verbatim copy is retained as [RecompFrontend/COPYING](lib/RecompFrontend/COPYING) for those inherited portions. This provenance does not establish a separate license grant for every later addition or independently written frontend/input file. The RaceWave46 license does not purport to resolve that remaining upstream scope.

## Build-tool provenance

[dependencies.json](dependencies.json) records revision evidence, archival RC6 input digests and separately labeled packaged component digests for v1.0.0. Vendored runtime, renderer and frontend trees include local modifications and must not be replaced with unmodified upstream releases when rebuilding this version.

The matching Windows `dxc.exe`, `dxcompiler.dll` and `dxil.dll` are obtained from Microsoft's pinned [v1.8.2502 release](https://github.com/microsoft/DirectXShaderCompiler/releases/tag/v1.8.2502) by the build bootstrap. Their exact hashes are recorded in `dependencies.json`. This release's [per-file license mapping](lib/rt64/src/contrib/dxc/validator-1.8.2502/RELEASE-NOTES.txt) assigns all three binaries to the [University of Illinois/NCSA license](lib/rt64/src/contrib/dxc/validator-1.8.2502/LICENSE-LLVM.txt). The exact tag's [compiler license](lib/rt64/src/contrib/dxc/validator-1.8.2502/LICENSE.TXT) and [third-party notices](lib/rt64/src/contrib/dxc/validator-1.8.2502/ThirdPartyNotices.txt) are also retained. The build acquires this complete toolchain into its local build directory; none of these 1.8.2502 binaries is included in the source archive. Existing notices remain applicable to the older headers, import libraries and other retained vendor files. The older release's Microsoft notice is retained for provenance and does not replace the newer release's stated license mapping.

Chris Lewis's [Snowboard Kids 2 recompilation articles](https://blog.chrislewis.au/) are credited as published technical references. This does not imply that he or any upstream contributor worked on or endorsed RaceWave46.
